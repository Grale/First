## soundbar-bot

[Soundbar Deal Bot](soundbar-bot/README.md): watches Cypriot and Greek shops (Electroline, Scandia,
MegaElectric, Stephanis, Public CY, Kotsovolos CY, Skroutz, Public GR, Kotsovolos GR) for wireless
soundbars with real Dolby Atmos height drivers, and alerts when one shop drops clearly below the others.
Same shape as the TV bot: local dashboard, ntfy push, Windows scheduled task.
